## Anatomia de cada relatório

Todas as páginas seguem a mesma espinha dorsal, para que a professora encontre os itens cobrados sempre no mesmo lugar:

1. **Metodologia do foco** — como o trabalho ocorreu, ferramentas, divisão;
2. **Artefato** — a imagem/modelo em si, versionada em `docs/assets/`;
3. **Descrição / leitura do artefato** — o que o modelo comunica;
4. **Rastreabilidade & Elos com Outros Artefatos** — para onde este artefato aponta e de onde veio;
5. **Senso Crítico** — decisões, limitações, alternativas descartadas;
6. **Participantes & Comprobatórios** — quem fez o quê, com link de commit;
7. **Referências** — link e/ou ABNT;
8. **Histórico de Versões**.

> Nenhum tópico deve ser omitido, conforme a diretriz.
